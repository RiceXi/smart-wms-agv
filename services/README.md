# 服务目录

每个子目录对应一个独立 Spring Boot 应用。M0 先建立健康检查和模块边界，业务实现按里程碑推进。

| 目录 | 负责人 | 主要接口 |
| --- | --- | --- |
| `gateway` | 成员一 | REST/WebSocket 统一入口、认证上下文 |
| `auth` | 成员一 | 登录、用户和角色 |
| `wms` | 成员一 | SKU、库位、库存、出库订单 |
| `task` | 成员一 | 任务池和任务状态机 |
| `dispatch` | 成员二 | 指派、路径、预约、死锁和充电 |
| `sim` | 成员二 | tick、AGV 运动、装卸和事件注入 |
| `push` | 成员三 | WebSocket 快照与增量 |
| `analytics` | 成员三 | 指标、瓶颈和任务时间线 |

每个服务必须包含：

- `README.md`：启动方式、端口、依赖、数据位置。
- `/actuator/health` 或等价健康检查。
- 配置和密钥模板，不提交真实密钥。
- 单元测试和至少一个集成测试。
- OpenAPI 或契约引用。

服务之间不得共享数据库表。跨服务状态通过 API 或事件传递。
