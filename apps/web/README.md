# Web 前端

负责人：成员三。

技术基线：Vue 3、TypeScript、Vite、Canvas 2D。

## 页面范围

- 仓库地图：地图层、AGV 层、任务连线、封路、热力和轨迹。
- 任务中心：任务队列、筛选、优先级、任务详情和时间线。
- 仿真控制：启动、暂停、单步、速度、重置、回放和事件注入。
- 分析面板：吞吐、平均耗时、AGV 利用率和瓶颈巷道。
- 告警面板：冲突、死锁、故障、超时和依赖异常。

## 必须遵守

- 地图坐标和 tick 使用 `packages/contracts` 定义。
- WebSocket 消息必须先校验 schema。
- 不使用前端随机数据伪装 AGV 位置。
- 动画使用统一渲染时钟，服务端事实状态保持可见。
- Playwright 主流程不使用 mock API。

启动命令和端口在 M0 工程骨架完成后补齐。
